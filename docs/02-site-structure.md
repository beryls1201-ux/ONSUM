# 02. 온숨(ONSUM) 사이트 구조

> 추후 결정 항목은 모두 정해졌습니다. (아래 5장 참고)

## 1. 페이지 목록

| 번호 | 페이지 | 포함하는 섹션 |
|---|---|---|
| ① | 메인 | 첫 화면, 나/선물 선택 |
| ② | 향 찾기 테스트 | 질문 단계(4개), 결과 화면 |
| ③ | 향 소개(상품) | 계절 탭, 향 12종(탭마다 아침·낮·밤 3종), 구매 영역 |
| ④ | 장바구니·주문·결제 | 장바구니, 선물 옵션, 결제, 주문 완료 |
| ⑤ | 브랜드 소개 | 온숨 브랜드 소개 |
| ⑥ | 고객 안내 | 배송·교환 안내, 문의, 비회원 주문 조회 |

## 2. 방문자 흐름별 페이지 구성

| 방문자 행동 | 필요한 정보·기능 | 배치할 페이지/섹션 | 다음 행동 |
|---|---|---|---|
| 사이트에 처음 들어온다 | 브랜드 소개 문장, 따뜻하고 아늑한 첫인상 | ① 메인: 첫 화면 | 나/선물 고르기 |
| 나를 위한 향인지 선물용인지 고른다 | '나를 위한 향 찾기 / 선물할 향 찾기' 두 갈래 | ① 메인: 선택 섹션 | 테스트 시작 |
| 질문에 답한다 | 일상 장면형 질문 4개, 진행 정도 표시, 선물용은 받는 사람 기준 | ② 향 찾기 테스트: 질문 단계 | 결과 보기 |
| 추천 향을 확인한다 | 향 12종 중 잘 맞는 3종을 1~3위 순위로 표시, 향마다 대표 색과 분위기 사진. 구매 버튼은 1위에만 | ② 향 찾기 테스트: 마지막 화면 | '자세히 보기' 또는 '구매하기', '테스트 다시 하기', '결과 링크 복사' |
| 향을 자세히 본다 | 계절 탭(봄·여름·가을·겨울)마다 아침·낮·밤 3종, 12종 모두 39,000원. 메뉴로 오면 현재 계절 탭. 테스트를 안 한 방문자에게 '내 향 찾기' 안내 | ③ 향 소개(상품): 한 페이지 + 계절 탭 | 구매하기 또는 내 향 찾기 |
| 구매 방식을 고른다 | '바로 결제'와 '장바구니 담기' 중 선택 | ② 결과 화면, ③ 향 소개의 구매 영역 | 결제 또는 장바구니 |
| 더 담거나 담은 상품을 확인한다 | 담은 상품 목록, 비어 있으면 빈 장바구니 안내 | ④ 장바구니·주문·결제: 장바구니 | 결제 또는 계속 둘러보기 (비어 있으면 내 향 찾기 · 향 소개 보기) |
| 선물 옵션을 고른다 (선물용) | 테스트 결과를 담은 메시지 카드(무료), 선물 포장(유료 3,000원) | ④ 장바구니·주문·결제: 선물 옵션 섹션 | 결제 |
| 결제한다 | 사이트 안에서 결제, 회원가입 없이 비회원 구매, 개인정보 수집·이용 동의(필수) | ④ 장바구니·주문·결제: 결제 | 주문 완료 |
| 주문을 마친다 | 주문 완료 안내, 비회원 주문 조회 방법 | ④ 장바구니·주문·결제: 완료 화면 | 메인으로 돌아가기 |
| 브랜드 이야기가 궁금하다 | 온숨 브랜드 소개 | ⑤ 브랜드 소개 | '향 찾기 시작'(주) · '향 소개 보기'(보조) |
| 배송·교환을 확인하거나 문의한다 | 배송·교환 안내, 문의(개인정보 수집·이용 동의 포함), 비회원 주문 조회 | ⑥ 고객 안내 | 메인으로 돌아가기 |

## 3. 메뉴 배치

- **상단 메뉴:** 브랜드 소개 · 향 찾기 · 향 소개 · 장바구니
- **하단(푸터):** 배송·교환 안내 · 문의 · 비회원 주문 조회
- **향 찾기 테스트 중(②):** 상단 메뉴 대신 '이전 · 로고 · 닫기'만 있는 테스트 헤더

## 4. 확정 항목

| 항목 | 확정 내용 |
|---|---|
| 나/선물 선택 위치 | 메인에서 선택 |
| 상단 메뉴 '향 찾기' 목적지 | ① 메인의 나/선물 선택 섹션으로 이동해, 고른 쪽 테스트로 시작 |
| 테스트 결과 위치 | 향 찾기 테스트의 마지막 화면 |
| 테스트 결과 표시 방식 | 향 12종 중 잘 맞는 3종을 1~3위 순위로 표시 (점수 규칙: 01-site-purpose.md 5장) |
| 결과 화면 버튼 | 구매 버튼은 1위 카드에만, 2·3위는 '자세히 보기'만. '테스트 다시 하기', '결과 링크 복사' 제공 |
| 테스트 질문 | 일상 장면형 4개 (01-site-purpose.md 5장) |
| 상품 구성 | 향 12종 = 계절 4 × 아침·낮·밤 (01-site-purpose.md 4장) |
| 상품 페이지 구성 | 한 페이지 + 계절 탭, 탭마다 3종. 기본 탭은 현재 계절 |
| 가격 | 12종 모두 동일가 39,000원 |
| 결과에서 구매로 가는 길 | '자세히 보기'와 '구매하기' 둘 다 제공 |
| 구매 방식 | '바로 결제'와 '장바구니 담기' 둘 다 제공, 구매자가 선택 |
| 회원 방식 | 비회원 구매만 (회원가입·로그인 없음) |
| 개인정보 동의 | 결제와 문의에 개인정보 수집·이용 동의(필수) 체크 |
| 빈 장바구니 | 빈 상태 안내 + '내 향 찾기' · '향 소개 보기' |
| 선물 옵션 | 메시지 카드 무료, 선물 포장 유료 옵션 3,000원 |
| 주문 완료 후 다음 행동 | 메인으로 돌아가기 |
| 브랜드 소개 후 다음 행동 | '향 찾기 시작'(주 버튼) · '향 소개 보기'(보조 버튼) |
| 고객 안내 후 다음 행동 | 메인으로 돌아가기 |
| 추가 페이지 | 브랜드 소개, 배송·교환 안내, 문의, 비회원 주문 조회 |
| 메뉴 배치 | 핵심만 상단, 나머지는 하단 |
| 페이지 묶음 | 장바구니·주문·결제를 한 페이지(④)로, 배송·교환 안내·문의·비회원 주문 조회를 한 페이지(⑥)로 |
