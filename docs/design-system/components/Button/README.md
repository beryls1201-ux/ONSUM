# Button

모든 버튼은 알약 모양이고, 한 화면의 핵심 행동 하나만 차콜 주요 버튼으로 둬요.

- **주요**: `ink` 바탕 + `on-ink` 글자, 높이 `control-lg`(56), 좌우 28, 16px 500. 다음으로 가는 버튼은 오른쪽에 → 아이콘. 마우스를 올리면 바탕이 `sage-deep`, 누르면 0.98배. 아직 고르지 않아 진행할 수 없으면 40% 흐리게 두고, 눌렀을 때 '확인' 안내를 보여줘요(비활성화하지 않음).
- **보조**: 투명 바탕 + `ink` 1.5px 테두리. 마우스를 올리면 바탕 `surface-linen`(리넨 위에서는 `surface-cream`).
- **담기 막대**: P3 향 카드 사진 아래에서 올라오는 흰 막대, 높이 44, `shadow-addbar`. 터치 화면에서는 항상 보여요.
- **아이콘 버튼**: 44×44 원, `line` 1px 테두리, `aria-label` 필수.
- 포커스: `sage-deep` 2px 외곽선, 간격 3px.
- 한 줄에 버튼이 둘이면 주요 버튼을 먼저(왼쪽) 둬요. 작은 카드 안 보조 버튼은 높이 48.
