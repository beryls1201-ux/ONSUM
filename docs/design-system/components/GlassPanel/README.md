# GlassPanel

첫 화면 사진 위, 왼쪽 아래에 놓는 반투명 유리 글 상자예요. 사이트에서 한 곳(P1 첫 화면)에만 써요.

- 크림 66% + 배경 흐림 20px + 흰 55% 1px 테두리, 모서리 28, 안쪽 36×40, 폭 600(최대 화면폭 - 80).
- 순서: H1 두 줄 → 본문 3줄(`ink-body`) → 숫자 3개(Quicksand 36 + 13px 라벨, 사이 가는 세로선) → 주요 버튼 하나.
- 숫자는 화면에 들어올 때 0에서 0.9초 동안 올라가요. 움직임 줄이기 설정이면 바로 최종 값.
- 사진 위에 색 막을 씌우지 않아요. 사진의 왼쪽 아래는 복잡하지 않게 찍어 달라고 이미지 목록에 적어 두었어요.
