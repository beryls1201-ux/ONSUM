# Chip

짧은 정보를 담는 알약 모양 표시예요. 누를 수 없고, 정보만 보여줘요.

- **단계 칩**: 리넨 알약(높이 48) + 크림 숫자 원(Quicksand). 칩 사이에 `line-strong` 가는 선. "① 장면 질문 4개 → ② 어울리는 향 3가지 추천 → ③ 바로 구매 또는 선물 카드"에만 써요.
- **답 칩**: 결과의 '나의 향 이야기'에서 고른 답. 리넨 위에서는 크림, 크림 위에서는 리넨 바탕.
- **순위 배지**: `apricot` 바탕 + 차콜 700 글자. 살구를 쓰는 몇 안 되는 자리예요.
- **상태 배지**: '결제 완료' 같은 주문 상태. `sage-deep` 1.5px 테두리 + 같은 색 글자.
- **대표 색 원**: 지름 12~20, 옅은 색이 묻히지 않게 차콜 15% 테두리.
