# ChoiceCard

방문자가 갈 길이나 답을 고르는 카드예요: P1의 나/선물 카드, P2의 사진 선택지, P5 끝의 두 갈래 카드.

- **갈래 카드**: 리넨 면, 모서리 24, 안쪽 20(아래 28~32). 위에 이미지(모서리 16), 아래에 H3 제목 + 설명 2줄 + 주요 버튼. 마우스를 올리면 4px 떠오르고 `shadow-lift`.
- **사진 선택지**: 같은 크기 사진 카드(250×240), 이름은 사진 안 아래쪽에 흰 글자로 겹치고 그 뒤에 아래쪽만 어두워지는 띠를 둬요. 고르면 `sage-deep` 3px 테두리 + 오른쪽 위 체크 원, `aria-pressed="true"`.
- 한 질문 안 선택지는 모두 같은 크기, 2~4열.
