# Header

상단 메뉴(C-GNB)는 P2를 뺀 모든 페이지에, 테스트 헤더(C-TGNB)는 P2에서만 써요.

- 높이 `header-h`(80), 콘텐츠 폭 `content-max` 안에 배치. 스크롤하면 위에 고정되고 바탕은 크림 92% + 배경 흐림 10px.
- **C-GNB**: 왼쪽 로고(높이 40) · 오른쪽 메뉴 4개(브랜드 소개, 향 찾기, 향 소개, 장바구니) 간격 40, 15px 500. 현재 페이지는 `sage-deep` 700 + 2px 밑줄, `aria-current="page"`. 장바구니 옆 숫자 원은 `ink` 바탕 Quicksand 12px, 담긴 직후 한 번 살짝 커졌다 돌아와요.
- **C-TGNB**: 왼쪽 ← 이전 · 가운데 로고 · 오른쪽 닫기(44 원, `line` 테두리). 닫기는 메인으로 가고 답변은 저장하지 않아요.
- 회원가입·로그인·검색창은 없어요. 모바일 햄버거 메뉴 모양은 미정이에요.
