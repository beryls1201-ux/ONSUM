# ScentCard

향 하나를 소개하는 카드예요: P3 향 카드(아침·낮·밤 3장), P2 결과 1위(가로형)와 2·3위 카드.

- 글자 순서와 크기: 장면 이름(H3 26, 크게) → 장면 문장(15, 중간) → 주요 노트(13, 작게). 가격은 '39,000원' 한 줄, 숫자는 Quicksand.
- 대표 색은 지름 14~20의 작은 원으로만(`scent-*`), 노트 풀이는 크림 상자(모서리 12)의 '노트 쉽게 보기'.
- **P3 카드**: 위에 라디오 + "가을 · 아침" + 대표 색 원. 고르면 카드에 `sage-deep` 2px 테두리, 아래 구매 영역에 그 향이 나와요. 마우스를 올리면 사진 아래에서 흰 담기 막대가 올라와요(터치 화면은 항상 표시).
- **결과 카드**: 순위 배지(`apricot` 바탕 + 차콜 글자)와 대표 색 원. 1위만 가로형으로 크게(이미지 560×380), 바로 결제·장바구니 담기·자세히 보기를 둬요. 2·3위는 자세히 보기만.
- 할인·별점·리뷰 수·배지 같은 판매 장치는 넣지 않아요.
