# Message

화면 안에 짧게 나타나는 안내 문구예요. 세 종류 모두 같은 모양이고 바탕색만 달라요.

- 모양: 알약 띠, 왼쪽 20px 원 아이콘, 차콜 글자 15px 500(입력칸 아래는 13px), 1px 테두리.
- **완료 ✓**: `sage-tint` 바탕, `sage-deep` 테두리·아이콘. 요청한 일이 끝났을 때. `role="status"`, 3초 뒤 사라져도 돼요.
- **오류 !**: `apricot-tint` 바탕, `apricot` 테두리·아이콘(아이콘 글자는 차콜). 입력이 틀렸거나 비었을 때, 처리 실패. `role="alert"`, 고칠 때까지 남겨요.
- **확인 i**: `surface-cream` 바탕, `check-line` 테두리, `ink` 아이콘. 아직 고르지 않은 것을 알려줄 때.
- **삭제 확인**: 그 줄 안에 리넨 상자로 열고 '취소'(보조) · '삭제'(주요)를 둬요. 브라우저 팝업은 쓰지 않아요.
- 문구는 부록 D의 17개 문장을 그대로 써요. 살구는 글자색으로 쓰지 않아요.
