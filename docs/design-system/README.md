# ONSUM 디자인 시스템

내 방의 온도를 바꾸는 향, 온숨. 몇 가지 질문으로 내 공간에 어울리는 향을 찾아주고, 그 향을 디퓨저로 전하는 브랜드의 웹사이트 디자인 기준이에요. Claude Design 캔버스 'ONSUM 메인 디자인'의 P1~P6 시안과 부록에서 실제로 쓴 값을 그대로 옮겼어요.

## 무엇을 위한 시스템인가

- **방문자**: 원룸에 사는 직장인(주), 선물하려는 사람(보조).
- **가장 중요한 행동**: 향 찾기 테스트 완료. 모든 화면은 이 행동을 방해하지 않게 조용해야 해요.
- **전할 인상**: 따뜻하고 아늑한. 자연스럽고 편안하며 과하지 않게.
- **피할 것**: 판매를 재촉하는 느낌, 정보가 많고 복잡한 느낌, 과하게 고급스러운 느낌. 할인율·쿠폰·별점·리뷰 수·형광 강조·프로모션 띠는 쓰지 않고, 가격은 '39,000원' 한 줄로만 보여줘요.

## 말투

퇴근길에 친구가 건네는 말처럼, 짧고 다정한 '~해요'체. 재촉하지 않고 장면으로 말해요.

> 오늘 방에 들어설 때, 어떤 공기가 반겨주면 좋을까요?

- 버튼은 할 일을 그대로 말해요: "나를 위한 향 찾기", "장바구니 담기", "결제하기".
- 안내 문구는 무엇이 잘못됐고 어떻게 하면 되는지 한 문장으로: "배송지의 상세 주소를 입력해주세요."
- 향은 이름보다 장면으로 소개해요. 글자 크기 순서는 장면 이름(크게) → 장면 문장(중간) → 노트(작게).

## 컬러

바탕 둘, 글자 넷, 포인트 둘로 끝나요. 나머지는 상태와 향 대표 색이에요.

| 역할 | 토큰 | 쓰는 곳 |
| --- | --- | --- |
| 바탕 | `surface-cream` | 페이지 바탕(약 60%) |
| 면 | `surface-linen` | 카드, 패널, 칩, 푸터 |
| 글자 | `ink` | 제목·본문, 주요 버튼 바탕 |
| 보조 글자 | `ink-subtle`(크림 위) · `ink-muted`(리넨 위) | 설명, 라벨 |
| 포인트 ① | `sage-deep` | 선택 테두리, 마우스 올림, 포커스, 현재 메뉴, 완료 |
| 포인트 ② | `apricot` | 진행 막대, 순위 배지, 로고 점, 오류 아이콘 |

규칙

- **핵심 버튼은 차콜 바탕 + 크림 글자.** 마우스를 올리면 바탕이 `sage-deep`으로 바뀌어요.
- **'지금 고른 것'은 `sage-deep` 테두리**(카드 2px, 사진 선택지 3px). 시즌 탭은 차콜 알약으로 표시해요.
- **살구는 글자색으로 쓰지 않아요**(크림 위 2.0:1). 넓은 면이나 큰 버튼에도 칠하지 않아요.
- **향 대표 색 12개**(`scent-*`)는 작은 원, 메시지 카드 띠, 포장 리본에만. 이미지가 아니라 화면 요소로 그려요.
- `sage-logo`는 로고 곡선 전용이에요.
- 사진 위에 색 막(세이지·살구 반투명)을 씌우지 않아요. 이미지 위 라벨은 차콜 55% 알약에 크림 글자.
- 빨간 할인 강조는 없어요.

## 안내 문구 (상태)

세 가지로만 나누고, 모두 **같은 모양**(둥근 띠 · 왼쪽 동그란 아이콘 · 차콜 글자 · 1px 테두리)에 **바탕색만** 달리해요. 브라우저 팝업은 쓰지 않아요.

| 종류 | 바탕 / 테두리 / 아이콘 | 언제 |
| --- | --- | --- |
| 완료 ✓ | `sage-tint` / `sage-deep` / `sage-deep` | 요청한 일이 끝났을 때 (담기, 링크 복사, 문의 접수) |
| 오류 ! | `apricot-tint` / `apricot` / `apricot` | 입력이 틀렸거나 비었을 때, 처리에 실패했을 때 |
| 확인 i | `surface-cream` / `check-line` / `ink` | 아직 고르지 않은 것을 알려주거나 한 번 더 물을 때 |

오류 입력칸은 `apricot` 2px 테두리 + `shadow-error`, 칸 바로 아래에 오류 띠를 둬요. 삭제 확인은 그 줄 안에 열리는 리넨 상자(취소 / 삭제)로 물어요.

## 타이포그래피

| 역할 | 글꼴 | 크기 |
| --- | --- | --- |
| 제목 | 고운돋움 Regular (`display`) | H1 44 · H2 40 · H3 28 · H4 22, 자간 -0.02~-0.015em |
| 본문·버튼 | Noto Sans KR 400/500/700 (`sans`) | 17 · 16 · 15 · 14 · 13 · 12 |
| 숫자 | Quicksand 600 (`num`) | 36 · 20 · 15 |

- 고운돋움은 굵기가 하나뿐이라 위계는 **크기와 여백**으로 잡아요. 굵게 만들지 않아요.
- 질문 화면에서는 질문(48px)이 가장 큰 글자예요.
- 숫자는 Quicksand, 바로 뒤의 '원' '개'는 본문 글꼴로 써요: `<span class="num">39,000</span>원`.
- 세 글꼴 모두 Google Fonts로 불러와요:
  `https://fonts.googleapis.com/css2?family=Gowun+Dodum&family=Noto+Sans+KR:wght@400;500;700&family=Quicksand:wght@500;600&display=swap`

## 레이아웃과 여백

여백을 넓게 쓰고, 한 화면에 섹션 하나씩 보여줘요.

- **콘텐츠 폭** `content-max` 1200px, 좌우 최소 24px (1440 화면에서 좌우 120px).
- **페이지 시작**: 제목으로 시작하면 64px(`space-16`), 큰 사진으로 시작하면 16px.
- **섹션 사이** 96px(`space-24`), **마지막 섹션 → 푸터** 128px(`space-32`).
- **묶음 사이** 48px(`space-12`): 제목 묶음 → 내용, 이어지는 영역.
- **묶음 안** 16–24px: 제목 → 설명 16, 카드 사이 24.
- 글은 왼쪽 정렬, 본문은 1~3줄로 짧게. 결과 1위만 자세히, 목록 카드는 짧게.
- 카드 2열(나/선물, 2·3위), 3열(향 카드), 패널+합계 2단(장바구니·결제). 작은 화면에서는 1열로 쌓아요(세부 기준은 미정).

## 모서리와 반복 요소

- 모든 버튼·칩·배지·탭·안내 띠는 알약(`radius-pill`).
- 카드 24 · 카드 속 이미지 16 · 큰 사진과 유리 상자 28 · 썸네일과 입력칸 8.
- 그림자는 카드에 마우스를 올렸을 때(`shadow-lift`)와 담기 막대에만. 평소의 카드는 리넨 면만으로 구분해요.
- 테두리 없는 리넨 카드 + 크림 바탕이 기본 조합이에요. 왼쪽 굵은 띠 카드는 쓰지 않아요.

## 아이콘

인라인 선 아이콘, 24 격자, `stroke-width` 1.8, 둥근 끝, `currentColor`. 화살표(→ 다음, ↓ 아래로, ← 이전), 닫기 ✕, 더하기·빼기, 체크, 링크, 다시 하기 정도만 써요. 이모지는 쓰지 않아요. 아이콘만 있는 버튼에는 `aria-label`을 달아요.

## 이미지

- 밝은 웜톤, 따뜻한 실내광. 어두운 톤은 '밤' 향 이미지 안에서만.
- 이미지 안에는 장면(과 제품)만, 이름·가격 같은 글자는 이미지 밖에.
- 향 이미지는 디퓨저를 같은 구도로 가운데, 배경만 향마다 다른 '방 안의 장면'. 같은 향은 어디서나 같은 이미지.
- 이미지가 준비되기 전에는 크기를 맞춘 자리 표시(웜톤 면 + `IMG-…` 라벨)를 둬요. 일러스트 자리는 점선 테두리.

## 움직임

짧고 조용하게, 핵심 행동을 돕는 곳에만.

- 숫자 카운트업 0.9초(끝으로 갈수록 느려짐), 결과 전환의 빛 1.5초.
- 버튼 바탕 색 0.2초, 카드 떠오름 0.35초, 담기 막대 올라옴 0.3초, 원룸 일러스트 교체 0.8초.
- 사용자가 '움직임 줄이기'를 켜면 모든 움직임을 생략하고 결과만 보여줘요(P5는 아침 그림만).

## 접근성

- 글자 대비 4.5:1 이상. `ink-subtle`은 크림 위, `ink-muted`는 리넨 위에 써요.
- 터치·클릭 영역 최소 44px(`control-sm`).
- 키보드 포커스는 `sage-deep` 2px 외곽선(간격 3px). 입력칸은 테두리 + `shadow-focus`.
- 선택은 색만이 아니라 테두리 굵기·체크 표시로도 보여줘요.

## 로고

'숨결' 로고: 소문자 워드마크 `onsum` 위로 흐르는 세이지 곡선과 살구 점. 상단 메뉴 왼쪽(높이 40px), 테스트 헤더 가운데, 푸터(높이 132px)에 써요. 파일은 Assets의 Logos에 있어요.

## 아직 정하지 않은 것

모바일 기준 폭과 세부 배치, 테스트 헤더의 모바일 모습, 스크롤 장면·로고 등장 등 나머지 움직임 수치, 디퓨저 용기 디자인, 실제 이미지 43장. 정해지면 이 문서와 `tokens.json`을 함께 고쳐요.
