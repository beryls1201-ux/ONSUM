# 05. 온숨(ONSUM) 레퍼런스 검토와 적용 방향

> 기준 문서: 01-site-purpose.md, 04-site-wireframe.md
> 화면이나 코드는 만들지 않았습니다. 문구·로고·고유 이미지는 가져오지 않았고, 구성과 표현 원리만 정리했습니다.
> 색상·글꼴·간격·움직임 수치는 확정하지 않았습니다. 화면에서 보이는 관계(크다/작다, 밝다/어둡다)만 적었습니다.

## 검토 관점

- **Pura는 컨셉 기준 레퍼런스입니다.** 온숨과 방향(공간에 맞는 향을 질문으로 찾아 디퓨저로 전함)이 같은 유일한 사이트라 전체 톤과 흐름을 참고합니다.
- **나머지(R2~R6)는 부분 참고 이미지입니다.** 여러 사이트에서 모은 향수 작은 이미지, 배치, 배너 예시이며, 필요한 표현만 골라 씁니다.
- **레퍼런스에 맞춰 구조를 바꾸지 않습니다.** 03 사이트맵과 04 와이어프레임의 페이지·섹션·흐름은 유지하고, 기존 섹션 안에서 표현과 배치를 다듬는 데만 씁니다. 구조나 공통 규칙을 바꿔야 하는 아이디어는 '보류'로 따로 모았습니다.
- 이 문서의 '적용'은 최종 와이어프레임(이미지 포함)에서 반영할 후보입니다.

## R1. Pura — 전체 구성 (컨셉 기준 레퍼런스)

- 링크: https://pura.com/

### 1. 직접 확인할 수 있는 특징

**레이아웃과 정렬**

- 헤더: 얇은 흰색 띠. 로고 왼쪽, 메뉴(스마트 디퓨저·향수·브랜드·선물하기·무료 디퓨저 행사) 가운데 왼쪽, 문장으로 찾는 검색창, 오른쪽 끝에 아이콘(관심·계정·장바구니). 헤더 아래에 가로 전체를 채우는 공지 띠가 있습니다.
- 첫 화면: 화면 전체를 채우는 영상/사진 위에 왼쪽 아래 정렬로 큰 제목 2줄, 본문 1~2줄, 둥근 버튼 1개. 아래 가운데에 슬라이드 점.
- '모든 방에 어울리는 디퓨저': 왼쪽에 글(제목·본문·버튼), 오른쪽에 집 단면 일러스트. 방마다 반투명 어두운 라벨(제품 작은 사진 + 방 크기 + 제품 이름)이 붙어 있고, 아래 가운데에 밑줄 텍스트 링크('모든 디퓨저를 비교해 보세요').
- '수백만 명이 푸라를 사랑하는 이유': 가운데 정렬 제목 아래 같은 크기 카드 3개. 카드 위쪽 대부분이 사진, 아래에 소제목과 본문 2줄.
- 페이지 텍스트 기준 홈 순서: 공지 띠 → 프로모션 → 첫 화면 → 세트 할인 → 포인트 → 선물 → 사랑받는 이유(카드 3개) → 방별 디퓨저 → 준비물 3단계(디퓨저 선택·향 선택·앱 설치) → 안전 기준 → 협업 브랜드 로고 → 뉴스레터 → 푸터 4묶음.
- 향 찾기 질문 화면(image 1): 일반 메뉴가 없고 '뒤로'(왼쪽), 로고(가운데), 닫기 원형 버튼(오른쪽)만 있습니다. 화면 폭을 거의 다 쓰는 왼쪽 정렬 질문, 그 아래 같은 크기 사진 카드 4개. 선택지 이름은 사진 아래쪽에 겹쳐 흰 글자로 가운데 정렬.
- 결과 화면(image 2): 위쪽 연한 배경 블록에 큰 제목('당신의 향수 이야기'), 설명 2줄, 그리고 '냄새', '느낌' 같은 항목을 한 줄씩 얇은 구분선으로 나누고 오른쪽에 작은 회색 칩으로 답을 보여줍니다. 아래 흰 배경에서 '원하는 향을 선택하세요' 소제목, 오른쪽에 '새로 고침 옵션' 링크, 그 아래 가로형 상품 카드 2열(왼쪽 사진, 오른쪽 이름·가격·별점·리뷰 수·노트 칩·설명 문단).

**제목과 본문의 크기 관계**

- 섹션 제목이 본문보다 몇 배 크고 가는 획으로 보입니다. 본문은 작고 짧게(1~3줄) 끊습니다.
- 질문 화면에서는 질문이 화면에서 가장 큰 요소이고, 선택지 이름은 사진 위 작은 글자입니다.
- 결과 화면의 소제목('원하는 향을 선택하세요')은 결과 제목보다 확실히 작아, 요약 → 선택 단계가 크기로 구분됩니다.

**여백**

- 제목 위아래와 카드 사이에 여백이 넉넉하고, 한 화면에 섹션 하나만 보이도록 나뉩니다.
- 질문 화면은 질문과 카드 4개 외에 다른 요소가 거의 없습니다.

**컬러**

- 바탕은 흰색·아주 연한 웜톤이고, 섹션 배경에 분홍~살구빛 그라데이션과 고운 노이즈가 깔려 있습니다.
- 주요 버튼은 검정(어두운) 둥근 알약 모양, 첫 화면 위 버튼은 흰색.
- 헤더 아래 공지 띠만 진한 주황 계열로 눈에 띕니다.
- 사진은 따뜻한 실내광 톤입니다.

**이미지와 정보의 배치**

- 사진이 정보를 대신합니다: 질문 선택지도 '공간 사진 + 짧은 이름'으로 고르게 합니다.
- 일러스트 위에 라벨을 얹어 '어느 공간에 어떤 제품'인지 한 장으로 보여줍니다.
- 결과 화면은 '왜 이 향인지(답 요약)'를 먼저 보여주고 그 다음 상품을 보여줍니다.

### 2. 그 특징이 만드는 인상

- 큰 제목과 넓은 여백, 연한 웜톤 그라데이션 → 부드럽고 가벼우며 서두르지 않는 느낌.
- 사진 카드로 고르는 질문 → 정답을 맞히는 시험이 아니라 '장면을 고르는' 가벼운 놀이처럼 느껴짐.
- 질문 화면의 최소 헤더 → 지금은 질문에만 집중하면 된다는 느낌.
- 결과 화면의 '나의 이야기' 요약 → 나를 위해 고른 추천이라는 느낌, 추천 근거가 보여 신뢰가 생김.
- 첫 화면의 선물 장면 영상 → 감성적이고 계절감 있는 첫인상.

### 4. 목적과 맞지 않아 그대로 적용하지 않을 부분

- **공지 띠, 세트 할인, 포인트, 뉴스레터 할인, 30일 체험 프로모션:** 01의 '판매를 재촉하는 느낌'과 맞지 않습니다.
- **첫 화면 슬라이드(여러 장 자동 전환):** 정보가 많아 보이고, 버튼이 하나인 첫 화면 목적과 맞지 않습니다.
- **문장 검색창:** 상품이 12종이라 필요성이 낮고, 상단 메뉴를 복잡하게 만듭니다.
- **협업 브랜드 로고 묶음, '300가지 이상의 향':** 온숨에는 해당 내용이 없습니다.
- **방 크기별 제품 비교, 앱 설치 단계:** 온숨은 디퓨저 하나의 구성이라 해당하지 않습니다.
- **결과 화면의 별점·리뷰 수·'새로 고침 옵션':** 별점과 리뷰는 아직 01에 정해진 데이터가 없고, 결과를 바꿔 보는 기능은 현재 '테스트 다시 하기'(P2-B6)로 대신합니다.
- **분홍 그라데이션 색 자체와 매우 가는 큰 제목:** 색은 온숨 톤으로 바꾸고, 글꼴 굵기는 캡처가 자동 번역 화면이라 근거로 쓰지 않습니다.

### 1. 직접 확인할 수 있는 특징

**레이아웃과 정렬**

- 헤더: 메뉴 왼쪽(가게▾·새로운·베스트셀러·협업▾), 로고 가운데, 아이콘 오른쪽(검색·계정·장바구니).

- 상품 4열 격자. 카드마다 정사각형 이미지, 그 아래 상품 이름과 가격을 **가운데 정렬**.
- 마우스를 올린 카드(image 3의 두 번째, image 11~14)에는 이미지 아래쪽에 흰색 가로 막대 '장바구니에 담기'와 오른쪽 위 원형 돋보기 버튼이 나타납니다.
- 페이지 텍스트 기준: 필터에 '계절(봄·여름·가을·겨울)'과 '향 유형(시트러스·얼씨·플로럴·프레시·프루티·구르망·스파이시·우디)'이 있고, 상품 75개, 아래에 '더 보기' 버튼. 목록 사이에 배너는 없습니다.

**제목과 본문의 크기 관계**

- 상품 이름은 굵게, 가격은 그보다 작게. 둘 다 짧은 한 줄입니다. 카드 안에 그 외 글자는 없습니다.

**여백**

- 카드 사이 간격이 일정하고, 이미지 안에서 제품이 가운데 같은 크기로 놓입니다.
- 이름과 가격 사이 간격이 좁아 한 묶음으로 읽힙니다.

**컬러**

- 목록 기본 이미지는 같은 연한 베이지 바탕에 제품(유리 용기 + 상자)을 둡니다.
- 소형 이미지(image 11~14)는 향마다 다른 장면 배경(금색 화병이 있는 실내, 꽃과 상자, 눈 덮인 산 모형, 어두운 바탕의 디저트)을 쓰지만, 제품은 항상 가운데에 라벨이 읽히는 크기로 있습니다.
- 버튼(장바구니 담기)은 흰색 막대, 글자는 검정.

**이미지와 정보의 배치**

- 이미지 안에는 제품과 장면만, 글자 정보(이름·가격)는 이미지 밖 아래에 둡니다.
- 구매 동작(장바구니 담기)은 이미지 위에 겹쳐 마우스를 올렸을 때만 보입니다.
- 일부 카드는 마우스를 올리면 이미지가 바뀌는 것으로 보입니다(이미지 대체 텍스트에 'hover' 표시).

- 같은 바탕·같은 구도의 이미지 → 정돈되고 고르기 쉬운 목록.
- 향마다 다른 장면 배경 → 이름만 보고도 '어떤 순간의 향'인지 떠오름.
- 이름·가격만 있는 카드 → 가볍고 부담 없는 쇼핑.
- 마우스를 올릴 때만 나타나는 구매 버튼 → 평소에는 조용하고, 원할 때 바로 담을 수 있음.

- 띠 안 구성: 큰 한글 향 이름 + 옆에 작은 영문 이름, 그 아래 설명 2줄, 그 아래 'TOP · MIDDLE · BASE' 작은 라벨 3개를 가로선으로 잇고 각 라벨 아래 노트를 작은 대문자로 나열.
- **제목과 본문의 크기 관계:** 향 이름이 가장 크고, 설명은 중간, 노트 목록은 가장 작습니다. 3단계 크기 차이가 분명합니다.
- **여백:** 띠 안에서 글이 왼쪽 위에 모이고 오른쪽은 사진이 보이도록 비워 둡니다.
- **컬러:** 띠마다 향을 떠올리게 하는 사진(파도, 오래된 서점, 꽃가게, 체리, 일랑일랑 꽃)을 어둡게 깔고 흰 글자를 올립니다.
- **이미지와 정보의 배치:** 사진이 배경 전체를 채우고, 정보는 사진 위에 얹습니다. 향 이름이 '북 스토어', '플라워 샵'처럼 장소·장면입니다.

### 2. 그 특징이 만드는 인상

- 사진에 빠져드는 몰입감, 차분하고 무게감 있는 분위기.
- 장면 이름 + 장면 사진이 겹쳐 향을 '경험'처럼 느끼게 함.
- 어두운 톤 때문에 고급스럽고 다소 무거운 인상.

### 3. 적용할 페이지·섹션과 이유

- 색상값, 글꼴, 간격, 움직임 수치. 캡처가 자동 번역 화면이라 글꼴은 확인할 수 없었고, 페이지 텍스트에서도 확인된 값이 없습니다.
- 위 항목은 레퍼런스 사이트의 값입니다. 온숨이 쓸 색과 로고는 이 문서 끝의 '컬러 가이드'와 '로고'에서 정했습니다.

#### 5. 쓰는 법

**이렇게 씁니다**
- 핵심 행동 버튼은 웜 차콜 바탕 + 크림 글자로 통일합니다.
- '지금 고른 것'(선택지, 탭, 상품)은 세이지 딥 테두리로 표시합니다.
- 살구는 진행 막대, 순위 배지, 짧은 태그에만 씁니다.
- 향 12종의 대표 색은 작은 원과 메시지 카드 띠에만 써서 사이트 색과 섞이지 않게 합니다.

**피합니다**
- 살구·버터·세이지 그린을 크림 바탕 위 글자색으로 쓰기.
- 살구를 넓은 배경이나 큰 버튼에 칠하기 — 들뜨고 재촉하는 느낌이 납니다.
- 빨강 계열 할인 강조 — 01 문서의 '판매 재촉' 방향과 맞지 않습니다.
- 사진 위에 세이지·살구 반투명 막 씌우기 — 장면 사진의 색을 가립니다.

**향수로 넓힐 때**
- 같은 팔레트를 그대로 쓰고, 향수 페이지만 웜 차콜 비중을 조금 높여 구분합니다.
- 디퓨저는 크림·리넨 중심, 향수는 차콜·세이지 딥 중심으로 두면 한 브랜드 안에서 자연스럽게 나뉩니다.
