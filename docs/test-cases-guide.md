### 1-2. 자주 쓰는 준비 방법

- **처음 상태로 시작**: 이 사이트에 저장된 장바구니·테스트 기록·모의 주문을 지우고 시작한다는 뜻입니다. 가장 쉬운 방법은 크롬 **시크릿 창**(Ctrl+Shift+N)에서 배포 주소를 여는 것입니다. 시크릿 창을 닫으면 기록이 사라지므로, 다음 '처음 상태' 케이스는 새 시크릿 창을 열어 시작합니다.
- **데스크톱 화면**: 별도 표시가 없는 케이스는 PC 브라우저 창을 넓게(가로 1024px 이상) 띄우고 마우스로 확인합니다.
- **390px 휴대폰 화면**: 실제 휴대폰이 있으면 그 휴대폰으로 확인합니다. PC에서는 크롬에서 F12 → 왼쪽 위 휴대폰 모양 아이콘(기기 툴바, Ctrl+Shift+M) → 화면 위쪽 너비 칸에 390을 적고 새로고침합니다. 이 상태에서는 마우스 클릭이 손가락 탭으로 처리됩니다.
- **모의 결제**: 결제는 실제로 돈이 나가지 않는 연습용입니다. 이름·연락처·주소는 아무 값(예: 테스트 / 010-0000-0000 / 서울시 마포구 온숨로 12 / 1층)이나 적으면 됩니다.
- **결과 칸**: 직접 확인한 뒤 통과·실패를 적습니다.
- **지문 수정 (2026-11-17)**: 동료 테스트에서 안내 문구가 어려워 실패로 기록된 TC-10·TC-16·TC-33의 테스트 방법·기대 결과를 알아보기 쉽게 고쳤습니다. 기능은 고치지 않았고, 고친 지문으로 같은 동료가 다시 테스트해 3건 모두 통과했습니다.
- **제외한 확인**: 브라우저별(크롬·엣지·사파리) 같은 화면·기능 확인과 Lighthouse 성능 점수 확인(옛 R-20, 처음 번호 TC-37·TC-38)은 prd.md 3장 '제외'로 옮겨 케이스에서 뺐습니다 (2026-11-17).

### 1-3. 답 고르는 법 (테스트 질문 화면)

질문마다 장면 사진 카드가 3~4장 있습니다. 카드 아래쪽에 적힌 글자(예: '따뜻한 차를 끓인다')를 보고 누른 뒤, 아래 **'다음 질문'** 버튼을 누릅니다. 마지막 4번째 질문에서는 이 버튼 이름이 **'추천 향 보기'**로 바뀝니다.

| 질문 | 카드에 적힌 글자 (왼쪽부터) |
| --- | --- |
| 질문 1 | 창문을 연다 / 꽃이나 화분을 본다 / 따뜻한 차를 끓인다 / 이불 속으로 들어간다 |
| 질문 2 | 출근 전 아침 / 쉬는 날 낮 / 잠들기 전 밤 |
| 질문 3 | 꽃이 핀 길 / 소나기 지나간 거리 / 단풍 든 산책로 / 눈 내리는 밤 |
| 질문 4 | 맑고 가벼운 / 꽃·과일처럼 환한 / 나무·차처럼 차분한 / 포근하고 달큼한 |
