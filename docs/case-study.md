## 02. 기획 의도

- **배경**: 온숨은 **"이름보다 먼저, 장면으로 만나는 향"**이라는 생각에서 출발했습니다.
  1. **향을 사려 해도, 정작 향을 알 수 없다.** 온라인에서 디퓨저를 찾아보면 향 설명은 '베르가못 · 통카빈'처럼 향료 이름뿐이고, 직접 맡아 볼 수도 없습니다. 향을 잘 모르는 사람은 이 이름만으로 어떤 향인지 떠올리기 어렵습니다.
  2. **그래서 향이 아닌 것으로 고르게 된다.** 쇼핑몰 화면에는 할인율·쿠폰·별점이 향보다 먼저 보여, 결국 '어떤 향이 좋은가'보다 '무엇이 더 싼가'로 고르게 됩니다.
  3. **하지만 좋아하는 장면은 누구나 고를 수 있다.** 향료 이름은 몰라도 '퇴근하고 따뜻한 차를 끓이는 저녁', '창문을 활짝 여는 아침'처럼 내가 좋아하는 순간은 바로 떠올릴 수 있습니다.
  4. **그래서 장면에서 향으로 가는 길을 만들었다.** 향의 이름부터 '첫 차 한 잔', '무드등 독서', '귤 까는 오후'처럼 원룸 직장인의 하루 속 '방 안의 장면'으로 지었고, 질문도 향료가 아니라 일상의 장면을 묻습니다. 좋아하는 장면 4개를 고르면, 향을 몰라도 나와 어울리는 향 3가지를 만날 수 있습니다.

  > **이름보다 먼저, 장면으로 만나는 향** — 향 이름, 테스트 질문, 결과의 향 사진, 브랜드 소개의 아침 → 낮 → 밤 장면까지, 사이트 전체가 이 한 문장을 따라갑니다.

- **타깃 페르소나** — 주 타깃은 20~30대입니다. 문서의 주·보조 방문자를 두 명의 인물로 정리했습니다.

  **① 주 페르소나 — 나를 위한 향을 찾는 사람**

  | 항목 | 내용 |
  | --- | --- |
  | 기본 정보 | 가명 '김서윤', 20대 후반 · 회사 근처 원룸에 혼자 사는 직장인 3년 차 |
  | 상황 | 평일엔 아침 일찍 나가 저녁 늦게 들어옵니다. 방이 작아 하루 대부분을 한 공간에서 보내다 보니, 퇴근하고 방에 들어섰을 때의 공기가 하루 기분을 좌우한다고 느낍니다. 방에 디퓨저 하나를 두고 싶지만 향을 잘 아는 편은 아닙니다. |
  | 이 사이트를 사용하는 상황 | 퇴근 후 침대에 누워 휴대폰으로 '방에 둘 디퓨저'를 찾다가 들어옵니다. '나를 위한 향 찾기'로 장면 질문 4개에 답하고, 결과 1위 향의 '노트 쉽게 보기'를 읽은 뒤 '바로 결제'로 주문합니다. |
  | 불편함(페인포인트) | ① '베르가못', '통카빈' 같은 이름을 봐도 어떤 향인지 떠오르지 않는다. ② 쇼핑몰에서는 할인·쿠폰·별점 정보가 너무 많아, 무엇을 기준으로 골라야 할지 모르겠다. ③ 맡아 보지 못하고 샀다가 방에 안 어울리면 어쩌나 싶어 결국 사지 못하고 창을 닫는다. ④ 회원가입부터 하라고 하면 귀찮아서 나간다. |
  | 사이트가 답하는 방식 | 향료 이름 대신 장면 사진 카드로 묻는 질문 4개(①③), 결과의 '노트 쉽게 보기'와 '나의 향 이야기'(①③), 가격은 '39,000원' 한 줄(②), 회원가입 없는 비회원 구매(④) |

  **② 보조 페르소나 — 선물할 향을 찾는 사람**

  | 항목 | 내용 |
  | --- | --- |
  | 기본 정보 | 가명 '이도현', 30대 초반 · 직장인, 곧 자취를 시작하는 친구의 집들이에 갈 예정 |
  | 상황 | 무난하면서도 성의 있어 보이는 선물을 찾고 있습니다. 디퓨저가 떠올랐지만, 친구가 어떤 향을 좋아하는지 정확히 모릅니다. |
  | 이 사이트를 사용하는 상황 | 점심시간에 '선물할 향 찾기'를 골라, 친구가 좋아할 장면을 떠올리며 질문에 답합니다. 결과에서 '바로 결제'를 누르면 '선물로 보내기'가 켜진 채로 열리고, 메시지 카드에 한마디를 적고 선물 포장을 더해 주문합니다. |
  | 불편함(페인포인트) | ① 받는 사람의 향 취향을 몰라 무엇을 골라야 할지 막막하다. ② 향료 이름만으로는 친구에게 어울리는지 판단할 수 없다. ③ 선물이라 카드와 포장까지 신경 써야 하는데, 따로 챙기기 번거롭다. |
  | 사이트가 답하는 방식 | 받는 사람 기준 문장으로 바뀌는 질문('그 사람은 하루를 마치고 방에 들어서면…')(①②), 향 이름·노트·장면이 담긴 무료 메시지 카드(최대 100자)와 선물 포장 3,000원(③) |

- **목표**: 원룸에 사는 직장인이나 선물하려는 사람이 따뜻하고 아늑한 분위기 속에서 부담 없이 향 찾기 테스트를 끝까지 마치고, 나 또는 받는 사람에게 맞는 향을 발견하게 하는 것
- **타깃 사용자 한 줄**: 20~30대, 향을 잘 모르지만 방에 둘 향을 찾는 원룸 직장인(주) · 연인·지인·친구에게 향을 선물하려는 사람(보조)
- **배경과 목표의 연결**: 배경의 문제를 '장면'으로 하나씩 풀었습니다.
  - 향료 이름으로는 향을 알 수 없다 → 향 이름과 질문을 모두 장면으로 바꾸고, 결과·향 소개 카드에 '노트 쉽게 보기'를 붙여 '베르가못 — 상큼하고 쌉싸름한 감귤 향'처럼 쉬운 말로 풉니다.
  - 맡아 볼 수 없다 → 향마다 '방 안의 장면' 사진과 장면 문장으로 향의 분위기를 전합니다.
  - 가격과 혜택으로 고르게 된다 → 할인·쿠폰·별점은 쓰지 않고, 가격은 '39,000원' 한 줄로만 보여 줍니다.
  - 장면은 누구나 고를 수 있다 → 일상의 장면 4개만 고르면 어울리는 향 3가지를 알려 주는 테스트를 사이트의 가장 중요한 행동으로 두었습니다.

## 03. 핵심 가설

- **가설 설정 배경 한 줄**: 와이어프레임과 브랜드 소개 문구가 '낯선 향료 이름보다 좋아하는 장면에서 시작해 보세요'라고 말하고, 사이트의 가장 중요한 행동은 '향 찾기 테스트 완료'입니다.
- **IF-THEN**
  - **IF**: 향료 이름 대신, 일상의 장면을 담은 같은 크기의 사진 카드 중 하나를 고르게 하고, 고르는 순간 테두리·체크·살구빛 물결로 바로 반응하며 '질문 n / 4' 진행 막대로 남은 질문을 보여 주면
  - **THEN**: 방문자는 향을 몰라도 질문 4개를 중간에 닫지 않고 끝까지 답해 결과 화면까지 이동하고, 결과에서 '자세히 보기'나 '바로 결제'로 다음 단계까지 이동한다.
- **검증 방향**: 이 사이트를 처음 보는 동료 1명이 실제 기기에서, 만든 사람의 안내 없이 핵심 흐름(우선순위 상·중 테스트 케이스)을 직접 따라 했습니다. 질문 단계(TC-07~TC-10), 결과(TC-12·TC-13), 처음부터 끝까지 이어지는 사용 흐름(TC-37 나를 위한 테스트, TC-38 390px 휴대폰 선물 주문)으로 끝까지 가는지 확인했습니다.
  - 1차 테스트: 38개 중 35개 통과, 3개 실패. 실패 3건은 기능이 아니라 테스트 가이드의 안내 문구가 어려워 생긴 것이었습니다.
  - 가이드 문구를 고친 뒤 같은 동료가 3건을 다시 테스트해 모두 통과했고, 38개 케이스를 모두 통과했습니다. (07-3)

- **비주얼 디렉션 한 줄**: 따뜻하고 아늑하게. 자연스럽고 편안하며 과하지 않게, 한 화면에 섹션 하나씩 조용하게.
- **컬러 선택 이유**
  - 오트 크림 #F7F2EA(바탕 약 60%) · 리넨 #EDE4D6(카드·요약 블록): 따뜻하고 아늑한 인상을 주는 웜톤 바탕
  - 웜 차콜 #2E2A26: 글자와 주요 버튼. 핵심 버튼은 차콜 바탕 + 크림 글자
  - 세이지 딥 #4F6B4A: 선택 테두리·마우스 올림·키보드 포커스에만
  - 살구 #F2A65A: 진행 막대·순위 배지·로고 점·퍼지는 빛에만. 크림 위 대비가 2.0:1이라 글자색으로 쓰지 않음
  - 향 대표 색 12종: 작은 원·메시지 카드 띠·포장 리본에만. 빨간 할인 강조와 사진 위 색 막은 쓰지 않음
- **타이포그래피 방향**
  - 제목 고운돋움, 본문·버튼 Noto Sans KR, 숫자 Quicksand
  - 제목 글꼴은 처음 고운바탕(명조)으로 제안했다가, 타깃 연령대에 비해 올드해 보여 고운돋움으로 바꿨습니다. 굵기가 하나뿐이라 위계는 크기와 여백으로 잡습니다.
- **인터랙션 무드**: 짧고 부드럽게. 움직임은 0.3~0.9초(결과 전환만 1.5초), 멈춤은 모두 ease이고, 기기에서 '움직임 줄이기'를 켜면 모두 생략합니다.

## 05. 인터랙션 설계

### 사이트 구성 한눈에 보기

```
P1 메인 ── 첫 화면(유리 글 상자 · 숫자 카운트업) → 나/선물 선택
   │
   ├─▶ P2 향 찾기 테스트 ── ★ 질문 4개(장면 사진 카드) → ★ 결과 전환 → 1~3위 결과
   │        │
```

★ = 아래 핵심 인터랙션 위치

### 핵심 인터랙션 ① 장면 사진 카드로 답하는 질문

- **무엇을**: 한 화면에 질문 하나와 같은 크기의 장면 사진 카드 3~4장을 보여 줍니다. 카드를 고르면 세이지 딥 테두리와 체크가 생기고, 누른 자리에서 옅은 살구빛 물결이 0.8초 동안 한 번 퍼집니다. '다음 질문'을 누르면 질문이 옆으로 짧게 밀리며 바뀌고, 살구 진행 막대와 '질문 n / 4'가 채워집니다. 선물 모드에서는 질문이 '그 사람' 기준 문장으로 바뀝니다.
- **왜**: 향료 이름 대신 장면으로 고르게 해서, 향을 몰라도 테스트를 끝까지 마치게 하려는 것입니다. 물결은 '향이 퍼진다'는 뜻을 담았습니다.
- **어떻게**: React 컴포넌트로 질문·선택지를 데이터(`src/data/questions.js`)에서 그리고, 답 4개를 점수 규칙(계절 +2·시간대 +3·향의 결 +3, 동점 규칙)으로 계산합니다. 휴대폰에서는 카드를 2열로 놓고 탭 영역을 44px 이상으로 둡니다.

### 핵심 인터랙션 ② 결과 전환과 순서대로 떠오르는 결과

- **무엇을**: '추천 향 보기'를 누르면 동그라미 3겹 빛이 1.5초 퍼지며 "답변에 어울리는 향을 고르고 있어요"를 보여 주고, 결과로 바뀝니다. 결과는 제목 → 나의 향 이야기 → 1위 → 2위 → 3위 → 버튼 순으로 0.1~0.16초 간격을 두고 아래에서 떠오르고, 1위 배지는 한 번 톡 튀어 오릅니다. 휴대폰에서는 전환 1초, 간격 절반입니다.
- **왜**: 답을 모두 고른 뒤 바로 결과를 띄우지 않고 1.5초의 짧은 쉼을 둔 것은, 고른 장면을 하나하나 살펴 신중하게 고르고 있다는 뜻을 전하기 위해서입니다. 쉼이 끝나면 '나의 향 이야기'로 내가 고른 답을 먼저 보여 주고 1위부터 추천을 이어서, '당신의 선택을 바탕으로 이 향을 추천했다'는 흐름이 읽히게 했습니다. 추천 이유를 납득한 방문자가 결과에서 '자세히 보기'나 '바로 결제'로 자연스럽게 넘어가게 하려는 것입니다.
- **어떻게**: 전환 블록과 결과 중 하나만 보이게 하고, 결과는 답을 주소(`/result?a=답4자리`)에 담아 링크로 열어도 같은 결과가 나오게 했습니다.

### 핵심 인터랙션 ③ 선물 메시지 카드 실시간 미리보기

- **무엇을**: 주문 단계에서 '선물로 보내기'를 켜면 메시지 카드·포장 영역이 0.35초 동안 펼쳐집니다. 보내는 사람 메시지(최대 100자)를 적으면 향 대표 색 띠·향 이름·노트·장면 문장이 들어간 카드에 바로 보이고, 마우스 위치에 따라 카드가 최대 6도 기울어집니다. 선물 테스트 결과에서 들어오면 '선물로 보내기'가 처음부터 켜져 있습니다.
- **왜**: 보조 방문자(선물하려는 사람)의 목적인 '받는 사람에게 맞는 향을 전하기'를 테스트 결과와 이어서 끝내게 하려는 것입니다.
- **어떻게**: 입력한 글을 같은 화면의 카드 미리보기에 바로 넣고, 포장(+3,000원)을 체크하면 금액에 더합니다. 휴대폰에서는 카드가 기울지 않습니다.

## 09. 회고

- **잘된 것**
  - 테마·구성·스타일·이미지·버튼·문구를 기획 문서에 하나씩 완성해 가며 만들어, AI의 추측이 아닌 내 의도와 일치하는 사이트를 만들었습니다.
  - "이름보다 먼저, 장면으로 만나는 향"이라는 한 문장이 향 이름, 테스트 질문, 결과의 향 사진, 브랜드 소개 스크롤까지 끝까지 이어졌습니다.
  - 동료 테스트에서 구현한 기능은 모두 동작했고, 안내 문구를 고친 뒤 38개 케이스를 모두 통과했습니다.
- **잘못된 것**
  - 결제·비회원 주문 조회 등을 구현했지만, 실제 서버나 DB가 아닌 웹사이트 안에서만 동작하는 방식이라 실제 사용될 페이지까지는 만들지 못했습니다.
  - 테스트 문서를 만든 사람의 눈으로 써서, 처음 보는 사람이 3건의 절차를 따라 하지 못했습니다.
- **도전한 것**
  - 기획 문서를 구현 설명서로 만들고, 7단계로 나눠 한 단계씩 승인하며 진행한 바이브코딩
  - 회원가입 없는 비회원 구매: 쇼핑몰은 회원가입이 기본이지만, 개인정보가 유출되거나 내 정보가 남는 것을 원하지 않는 요즘 흐름을 생각해 회원가입 없이 주문하고, 주문번호와 비밀번호로만 조회하게 했습니다. 판매를 위한 장치보다 고객을 소중히 여긴다는 태도를 담고 싶었습니다.
  - 요구사항 정의서와 테스트 케이스를 쓰고, 동료에게 안내 없이 테스트를 맡긴 뒤 결과를 반영한 것
- **다음에 개선할 것**

## 10. 가설 검증

- **처음과 끝을 연결하는 서사**: 가격과 혜택으로 재촉하는 화면, 낯선 향료 이름으로만 고르는 화면에서 출발해, 일상의 장면 4개만 고르면 향 3가지를 알려 주는 테스트를 만들었습니다.
- **검증 근거**: 장면 사진 카드 질문부터 결과까지 이어지는 사용 흐름 케이스 TC-37(PC)과 TC-38(390px 휴대폰, 선물 주문까지)이 통과했습니다. 실패로 기록된 3건(키보드로 답하는 TC-10 포함)은 기능이 아니라 안내 문구가 어려워 생긴 것이었습니다.
- **확인한 범위와 한계**
  - 테스트한 사람은 동료 1명이고, 실제 기기에서 안내 없이 우선순위 상·중 케이스를 확인했습니다. 한 사람의 결과라 일반화하기는 어렵습니다.
  - 테스트 케이스는 정해진 절차대로 따라 하며 '끝까지 갈 수 있는가'를 확인한 것입니다. 방문자가 스스로 끝까지 가는지(중간에 닫는 비율 등)는 측정하지 않았습니다.
  - 실제 방문자 데이터와 수치는 없습니다. 이 결과만으로 가설이 검증되었다고 말하기는 어렵습니다.
- **짧고 인상적으로**: 향을 몰라도 장면을 고르면 향을 찾을 수 있게 만들었고, 정해진 절차로는 처음부터 결과와 선물 주문까지 막힘없이 이어지는 것을 확인했습니다. 실제 방문자가 스스로 끝까지 가는지는 다음에 확인할 몫입니다.
- **마무리 한 문장**: 이름보다 먼저, 장면으로 만나는 향.
