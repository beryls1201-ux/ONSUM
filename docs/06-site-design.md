## 2. 디자인 방향

- 전할 인상: 따뜻하고 아늑한. 자연스럽고 편안하며 과하지 않게.
- 가장 중요한 행동(향 찾기 테스트 완료)을 방해하지 않도록 화면은 조용하게, 한 화면에 섹션 하나씩.
- 피할 것: 판매를 재촉하는 느낌, 정보가 많고 복잡한 느낌, 과하게 고급스러운 느낌. 할인율·쿠폰·별점·리뷰 수·형광 강조·프로모션 띠는 쓰지 않고, 가격은 '39,000원' 한 줄.

### 3-3. 컬러 규칙

- 핵심 버튼은 차콜 바탕 + 크림 글자. 마우스를 올리면 바탕이 세이지 딥으로 바뀝니다(터치 화면에서는 바뀌지 않음).
- '지금 고른 것'은 세이지 딥 테두리(카드 2px, 사진 선택지 3px). 계절 탭만 차콜 알약으로 표시합니다.
- 살구는 글자색으로 쓰지 않습니다(크림 위 대비 2.0:1). 넓은 면·큰 버튼에도 칠하지 않습니다. 작은 점·막대·배지·옅은 빛으로만 씁니다.
- 향 대표 색은 작은 원, 메시지 카드 띠, 포장 리본에만 씁니다. 이미지가 아니라 화면 요소로 그립니다.
- 세이지 그린(#7A9A74)은 로고 곡선 전용입니다. 버터 옐로(#F4D88A)는 쓰지 않습니다.
- 사진 위에 색 막(세이지·살구 반투명)을 씌우지 않습니다. 이미지 위 라벨은 차콜 55% 알약 + 크림 글자.
- 빨간 할인 강조는 없습니다.

## 4. 안내 문구 (상태 표시)

세 가지로만 나누고, 모두 같은 모양(둥근 띠 · 왼쪽 20px 원 아이콘 · 차콜 글자 · 1px 테두리)에 바탕색만 달리합니다. 코드는 `src/index.css`의 `.notice` + `.notice-ok` / `.notice-err` / `.notice-chk`, 입력칸 아래는 `.notice-sm`(13px). 브라우저 팝업은 쓰지 않습니다.

| 종류 | 바탕 / 테두리 / 아이콘 | 언제 | 접근성 |
|---|---|---|---|
| 완료 ✓ | `sage-tint` / `sage-deep` / `sage-deep` | 요청한 일이 끝났을 때 (담기, 링크 복사, 문의 접수) | `role="status"` |

| 확인 i | `surface-cream` / `check-line` / `ink` | 아직 고르지 않은 것을 알려주거나 한 번 더 물을 때 | `role="alert"` |

불러오는 방식: Google Fonts 링크 유지 (`index.html`)
`https://fonts.googleapis.com/css2?family=Gowun+Dodum&family=Noto+Sans+KR:wght@400;500;700&family=Quicksand:wght@500;600&display=swap`

- 제목 글꼴은 처음 고운바탕(명조)으로 제안했다가, 타깃 연령대에 비해 올드해 보인다는 의견에 따라 고운돋움으로 바꿨습니다.
- 고운돋움은 굵기가 하나뿐이라 위계는 크기와 여백으로 잡습니다.
- 숫자는 Quicksand, 바로 뒤 '원' '개'는 본문 글꼴로 씁니다.

### 9-2. 배치와 정렬

- 2~4열 카드는 1열로 쌓습니다. 테스트 선택지만 휴대폰에서 2열(이름 글자 15px).

- 가운데 정렬: 푸터 문구·메뉴·로고 / 메인 '진행 순서' 칩(세로로 쌓고 칩 폭 21.4em ≈ 321px, 칩 사이 12px 세로 연결선) / 버튼 묶음(테스트 이전·다음, 결과 1위 버튼, 구매 영역 버튼, 문의 보내기 줄).
- 왼쪽 정렬 유지: 페이지·섹션 제목, 설명 글.
- 브랜드 소개: 장면 일러스트·선물 사진을 내용 폭에 꽉 채움, 장면 썸네일 3개를 가로로 두고 위 큰 그림과 양쪽 끝을 맞춤, 휴대폰에서 '향 소개' 계절 색 점을 2열 × 2줄로.
- 줄바꿈: 한글은 띄어쓰기 단위로만 줄바꿈(`keep-all`), 제목은 줄 길이를 고르게(`balance`). 주문번호·이메일처럼 띄어쓰기 없는 긴 글은 넘치지 않게 끊음.

## 12. 접근성

- 글자 대비 4.5:1 이상. `ink-subtle`은 크림 위, `ink-muted`는 리넨 위에 씁니다.
- 터치·클릭 영역 최소 44px.
- 키보드 포커스는 세이지 딥 2px 외곽선(간격 3px), 입력칸은 테두리 + `shadow-focus`.
- 선택 상태는 색만이 아니라 테두리 굵기·체크 표시로도 보여줍니다.
- 필수 칸은 ✱ 표시와 함께 `aria-required="true"`.
- 접혀 있는 영역(FAQ 답, 선물 옵션)은 `inert`로 포커스에서 뺍니다.
- 버튼은 `<button>`, 이동은 `<a href>`, 입력은 `<label>`이 붙은 `<input>`. 탭은 `role="tablist"`, 토글은 `role="switch"`, 진행 막대는 `role="progressbar"`, FAQ는 `aria-expanded`.

- 밝은 웜톤, 따뜻한 실내광. 어두운 톤은 '밤' 향 이미지 안에서만.
- 이미지 안에는 장면(과 제품)만, 이름·가격 같은 글자는 이미지 밖에.
- 향 이미지: 디퓨저를 같은 구도로 가운데, 배경만 향마다 다른 '방 안의 장면'. 같은 향은 결과·상품 카드·구매 영역·장바구니에서 같은 이미지.
- 디퓨저 용기: 낮고 둥근 투명 유리병 + 원목 캡 + 리드 스틱, 크림색 종이 라벨. 12종 모두 같은 병.
- 향 이미지 촬영: 정면, 테이블보다 살짝 위. 소품은 좌우 가장자리에, 디퓨저 위아래는 여유 있게(96×96~548×200으로 잘려 쓰임). 대표 색은 소품과 빛으로만. 향별 연출컷은 PROJECT_CONTEXT.md 6-2 ③.
- 파일: 화면에서 가장 크게 쓰이는 폭의 2배로 줄인 WebP(품질 80)를 `src/assets/page*/`에 넣고, 이름은 `페이지-섹션 · IMG-ID.webp`(예: `P1-S1 · IMG-P1-01.webp`). JPG 편집 원본은 `docs/assets`.
- 이미지 파일이 없을 때만 크기를 맞춘 자리 표시(웜톤 면 + `IMG-…` 라벨)를 둡니다.
- 이미지 목록(43장)과 크기는 PROJECT_CONTEXT.md 6-2를 따릅니다.

## 15. 말투

퇴근길에 친구가 건네는 말처럼, 짧고 다정한 '~해요'체. 재촉하지 않고 장면으로 말합니다.

> 오늘 방에 들어설 때, 어떤 공기가 반겨주면 좋을까요?

- 버튼은 할 일을 그대로 말합니다: "나를 위한 향 찾기", "장바구니 담기", "결제하기".
- 안내 문구는 무엇을 하면 되는지 한 문장으로: "상세 주소까지 적어 주세요."
- '~해주세요'는 '~해 주세요'로 띄어 쓰고, '선택·입력'보다 '고르기·적기'처럼 쉬운 말을 씁니다. 바꾼 문구 전체는 `docs/copy-changes.md`.

## 16. 남은 확인 사항

- 개인정보 수집·이용 동의 전문과 배송·교환 정책 숫자(결제 후 1~2일 출고·2~3일 도착, 받은 날부터 7일 안 교환·반품, 단순 변심 왕복 6,000원)는 포트폴리오용 예시입니다. 실제 운영 전 전문가 확인과 실제 정책으로 교체가 필요합니다.
- 디자인 시안(Claude Design)과 디자인 시스템 아티팩트는 구현 전 값이라, 이 문서와 다른 부분(유리 상자, 담기 막대, 카드 제목 크기, 안내 문구, 반응형, 움직임)이 남아 있습니다.
