# 07. 온숨(ONSUM) 이미지 생성 프롬프트 (나노바나나용)

> PROJECT_CONTEXT.md 6-2의 이미지 43장을 만들기 위한 프롬프트입니다. 페이지 순서로 정리했습니다.
> 각 영문 프롬프트는 복사해서 그대로 쓸 수 있도록 공통 규칙까지 넣어 두었습니다.

## 사용 방법

1. **향 이미지는 SC-01을 먼저 만듭니다.** 마음에 드는 결과가 나오면 SC-02~12를 만들 때 그 이미지를 참고 이미지로 함께 넣고, 프롬프트 앞에 `Keep the exact same diffuser bottle, camera angle and product size as the reference image.`를 붙입니다. 12장의 병·구도·크기를 맞추기 위해서입니다.
2. **원룸 일러스트는 P5-02(아침)를 먼저 만들고**, P5-03·04를 만들 때 참고 이미지로 넣습니다. 프롬프트 앞에 `Use the reference illustration and keep the room, layout and every object exactly the same; change only the light and colors.`를 붙입니다.
3. **계절 사진 SE-01~04**도 첫 장을 참고 이미지로 넣어 톤과 구도를 맞춥니다.
4. **로고와 글자는 이미지에 넣지 않습니다.** 디퓨저 라벨은 빈 크림색 라벨로 만들고, 로고는 나중에 합성합니다(AI가 만든 글자는 깨지기 쉽습니다).
5. **비율 → 원본 크기:** 프롬프트에 적은 비율로 만든 뒤, 표시 크기의 2배로 잘라 WebP로 저장합니다. 편집 원본(JPG/PNG)은 따로 보관합니다.
6. 페이지 칸의 `(표시 크기 / 생성 비율)`을 보고 자를 크기를 확인합니다.
