## 1. 테스트 환경과 작성 기준

- **데스크톱**: 화면 폭 1024px 이상 + 마우스 (prd.md R-18의 데스크톱 기준). 별도 표시가 없는 케이스는 데스크톱에서 확인합니다.
- **모바일·태블릿**: 390px 화면에서 손가락 탭으로 확인합니다. (prd.md 기준 767px 이하 = 휴대폰)
- **처음 상태로 시작**: '처음 상태'라고 적힌 케이스는 브라우저에서 이 사이트의 저장 데이터(장바구니·테스트 기록·모의 주문)를 지운 뒤 시작합니다.
- **테스트 항목·우선순위**: prd.md의 요구사항 문장과 우선순위를 그대로 씁니다. 사용 흐름 케이스(TC-37·TC-38)는 여러 요구사항을 이어서 확인하므로, 포함된 요구사항 중 가장 높은 우선순위를 씁니다.
- **점수 예시**: TC-12·TC-13·TC-14의 답과 순위는 prd.md R-07의 점수 규칙(동점이면 향의 결 → 시간대 → 계절 → 현재 계절)으로 계산한 값입니다. 사이트의 점수 계산 코드로도 같은 결과가 나오는 것을 확인했어요.
- **결과 칸**: 직접 확인한 뒤 채웁니다.
- **제외한 확인**: 브라우저별(크롬·엣지·사파리) 같은 화면·기능 확인과 Lighthouse 성능 점수 확인(옛 R-20, 처음 번호 TC-37·TC-38)은 prd.md 3장 '제외'로 옮겨 케이스에서 뺐습니다 (2026-11-17).
