## 2. 표기 규칙 (범례)

| 표기 | 뜻 |
|---|---|
| 글자 | 화면 문구 초안 (회색 선 = 문구 미정) |
| 사진 | 이미지 자리 (Figma 안의 사진은 실습용 샘플) |
| 점선 상자 | 일러스트 자리 (사진 아님) |
| X 상자 | 이미지 |
| 얇은 테두리 상자 | 버튼·입력·선택·조절 요소 |
| 굵은 검정 테두리 (3px) | 핵심 행동 (표에서 ★) |
| 파란 태그 | ID: 메뉴 `M-`, 페이지 `P`, 섹션 `P?-S?`, 버튼 `P?-B?`, 공통 영역 `C-` |
| 파란 글씨 ※ | 설계 메모 |

**ID 규칙**

- 공통 영역: `C-GNB` 상단 메뉴, `C-FTR` 하단 메뉴(푸터), `C-TGNB` 테스트 헤더. C-FTR은 모든 페이지, C-GNB는 P2를 제외한 모든 페이지에 들어가고, P2(향 찾기 테스트)에서는 C-GNB 대신 C-TGNB를 씁니다.
- 메뉴: `M-01`~`M-08`
- 페이지: `P1`~`P6`
- 섹션: `P1-S1`처럼 페이지 번호 + 섹션 번호. 화면 안에서 위에서 아래로 쌓입니다.
- 버튼: `P1-B1`처럼 페이지 번호 + 버튼 번호. 같은 버튼이 반복되면 같은 ID를 씁니다 (예: 결과 카드 3장의 `P2-B3`). 나중에 추가한 버튼은 뒷번호를 받습니다 (예: `P4-B7`, `P4-B8`).
- 화면 속 향은 가을 탭 예시입니다. 향 이름·노트는 01-site-purpose.md 4장의 12종 표를 따릅니다.
- 사진·일러스트 자리는 크기만 정합니다. Figma에 들어 있는 사진은 실습용 샘플이라 이 문서에서는 다루지 않습니다. 이미지 규칙은 05-site-reference.md의 A7(같은 구도 + 향마다 다른 장면 배경)을 따릅니다.
- 로고는 05-site-reference.md '로고'의 '숨결' 기본 로고입니다. Figma에서는 `ONSUM Logo / Primary` 컴포넌트의 인스턴스로 들어 있습니다.
- 색은 05-site-reference.md '컬러 가이드'의 팔레트를 따릅니다.
- 움직임(카운트업, 전환, 스크롤 장면, 로고 등장)은 사용자가 '움직임 줄이기'를 켜 두면 바로 결과만 보여줍니다.

## 3. 공통 영역

**C-GNB 상단 메뉴** (P2를 제외한 모든 페이지)

- `M-01` 로고 (숨결 로고)
- 버튼 `M-02` 브랜드 소개
- 버튼 `M-03` 향 찾기
- 버튼 `M-04` 향 소개
- 버튼 `M-05` 장바구니

**C-FTR 하단 메뉴(푸터)** (모든 페이지)

- 문구: "온숨 · 취향을 발견하고, 향으로 마음을 전하세요. / 향 선택부터 주문 확인까지, 필요한 안내를 만나보세요."
- 버튼 `M-06` 배송·교환 안내
- 버튼 `M-07` 문의
- 버튼 `M-08` 비회원 주문 조회
- 푸터 로고 (숨결 로고)
- ※ 페이지 끝에 닿으면 ONSUM 로고가 한 글자씩 아래에서 올라옴 (움직임 줄이기 설정이면 바로 표시)

**C-TGNB 테스트 헤더** (P2 향 찾기 테스트에서만, C-GNB 대신)

- 버튼 `P2-B1` ← 이전
- `M-01` 로고 (숨결 로고)
- 버튼 `P2-B8` 닫기 ✕
- ※ 테스트 중(P2)에는 상단 메뉴 대신 이 헤더만 표시. 이전은 질문 단계의 이전과 같은 동작, 닫기는 메인(P1)으로 이동하며 진행 중인 답변은 저장하지 않음
