# 01. 온숨(ONSUM) 사이트 목적

> 내 방의 온도를 바꾸는 향, 온숨.
> 온숨은 몇 가지 질문으로 내 공간에 어울리는 향을 찾아주고, 그 향을 디퓨저로 전하는 브랜드입니다.

---

## 1. 사이트 목적 한 문장

원룸에 사는 직장인이, 또는 소중한 사람에게 선물하려는 사람이 따뜻하고 아늑한 분위기 속에서 부담 없이 향 찾기 테스트를 끝까지 마치고, 나 또는 받는 사람에게 맞는 향을 발견하게 하는 것.

## 2. 주요 방문자와 방문자의 필요

| 구분 | 방문자 | 필요 |
|---|---|---|
| 주 방문자 | 원룸에 사는 직장인 | 나에게 맞는 향 찾기 |
| 보조 방문자 | 연인·지인·친구에게 선물하려는 사람 | 받는 사람에게 맞는 향 찾기 |

**주요 기기**

- 데스크톱 기준으로 진행합니다.

## 3. 가장 중요한 행동과 보조적인 행동

**가장 중요한 행동**

- 주 방문자: 향 찾기 테스트 완료
- 보조 방문자: 선물용 향 찾기 테스트 완료

**보조적인 행동**

- 추천받은 디퓨저 구매 (사이트 안에서 결제, 회원가입 없이 비회원 구매)
- 선물용 구매 시, 향 찾기 테스트 결과를 담은 메시지 카드(무료)와 선물 포장(유료 옵션) 제공

**향 찾기 테스트 구성**

- 질문 4개 (아래 5장 '향 찾기 테스트 질문' 참고)
- 답변으로 향 12종 전체에 점수를 매겨, 잘 맞는 3종을 1~3위 순위로 보여줌
- 결과 화면에서는 향마다 대표 색과 분위기 사진으로 향의 느낌을 전달

**상품 구성과 가격**

- 디퓨저 향 12종: 계절 4가지(봄·여름·가을·겨울) × 하루 시간 3가지(아침·낮·밤)
- 향 이름은 원룸 직장인의 하루 속 '방 안의 장면'으로 지음
- 가격: 12종 모두 동일가 39,000원 (2~5만 원대 안)

## 5. 향 찾기 테스트 질문 (일상 장면형)

질문마다 계절·시간대·향의 결 중 하나에 점수를 줍니다. 선물용은 같은 질문을 받는 사람 기준으로 바꿔 묻습니다. (예: '그 사람은 하루를 마치고 방에 들어서면, 가장 먼저 무엇을 하고 싶어 할까요?')

| 번호 | 질문 | 선택지 | 점수를 주는 기준 |
|---|---|---|---|
| Q1 | 하루를 마치고 방에 들어서면, 가장 먼저 무엇을 하고 싶나요? | 창문을 연다 / 꽃이나 화분을 본다 / 따뜻한 차를 끓인다 / 이불 속으로 들어간다 | 계절 (여름 / 봄 / 가을 / 겨울) |
| Q2 | 내 방이 가장 좋은 시간은 | 출근 전 아침 / 쉬는 날 낮 / 잠들기 전 밤 | 시간대 |
| Q3 | 창밖으로 보고 싶은 풍경은 | 꽃이 핀 길 / 소나기 지나간 거리 / 단풍 든 산책로 / 눈 내리는 밤 | 계절 |
| Q4 | 끌리는 향의 느낌은 | 맑고 가벼운 / 꽃·과일처럼 환한 / 나무·차처럼 차분한 / 포근하고 달큰한 | 향의 결 |

### 점수 규칙

선택한 답마다 아래 점수를 해당 향에 더하고, 합계가 높은 순서로 1~3위를 정합니다. (최고 10점)

| 질문 | 선택지 → 점수를 받는 향 | 점수 |
|---|---|---|
| Q1 계절 | 창문을 연다 → 여름 3종 / 꽃이나 화분을 본다 → 봄 3종 / 따뜻한 차를 끓인다 → 가을 3종 / 이불 속으로 들어간다 → 겨울 3종 | +2 |
| Q2 시간대 | 출근 전 아침 → 아침 4종 / 쉬는 날 낮 → 낮 4종 / 잠들기 전 밤 → 밤 4종 | +3 |
| Q3 계절 | 꽃이 핀 길 → 봄 3종 / 소나기 지나간 거리 → 여름 3종 / 단풍 든 산책로 → 가을 3종 / 눈 내리는 밤 → 겨울 3종 | +2 |
| Q4 향의 결 | 아래 '향의 결' 묶음 중 고른 묶음의 3종 | +3 |

**향의 결 묶음 (Q4)**

| 선택지 | 해당 향 |
|---|---|
| 맑고 가벼운 | 봄 아침 창을 연 아침 · 여름 아침 찬물 샤워 · 여름 낮 마른 빨래 |
| 꽃·과일처럼 환한 | 봄 낮 꽃병 옆 오후 · 봄 밤 산책 끝난 밤 · 여름 밤 열어둔 창 |
| 나무·차처럼 차분한 | 가을 아침 첫 차 한 잔 · 가을 낮 길어진 햇살 · 겨울 낮 귤 까는 오후 |
| 포근하고 달큰한 | 가을 밤 무드등 독서 · 겨울 아침 이불 속 5분 · 겨울 밤 촛불 켠 밤 |

**동점일 때:** 향의 결 점수 → 시간대 점수 → 계절 점수 순으로 높은 쪽, 그래도 같으면 현재 계절의 향을 앞에 둡니다.

**결과 다시 보기:** 결과 화면의 '결과 링크 복사'로 받은 링크를 열면 같은 결과 화면이 보입니다. 비회원도 결과를 다시 볼 수 있습니다.

## 6. 선물 메시지 카드와 포장

- **메시지 카드 (무료):** 추천 향의 대표 색 띠, 계절·시간, 향 이름, 주요 노트, 장면 문장 한 줄, 보내는 사람이 직접 쓰는 메시지(100자)
- **선물 포장 (유료 옵션, 3,000원):** 크라프트 상자 + 향 대표 색 리본

## 7. 전달하고 싶은 인상과 피하고 싶은 방향

주 방문자와 보조 방문자에게 공통으로 적용합니다.

**전달하고 싶은 인상**

- 따뜻하고 아늑한

**피하고 싶은 방향**

- 판매를 재촉하는 느낌
- 정보가 너무 많고 복잡한 느낌
- 과하게 고급스러운 느낌
